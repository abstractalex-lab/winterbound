# Creative Mode: Dynamic NPC Quest System with Procedural Quest Generation

## Scenario: The Wandering Storytellers

### The Story

In the lands of Earth and the Plains, ancient NPCs known as the **Wandering Storytellers** have emerged—mysterious beings who appear in villages, taverns, and crossroads. Unlike the hostile creatures that roam the world, these NPCs are allies who weave tales of adventure and challenge.

Each Storyteller is unique, dwelling in different locations and generating quests tailored to the current state of the world. They observe:
- What creatures the player has defeated
- What items the player has collected
- The current state of the world (which grounds have changed, what's been destroyed)
- The player's survival status (health, hunger, warmth)

Based on these observations, the Storytellers craft dynamic, personalized quests using an ancient oracle—the **Gemini API**. Each quest is:
- **Unique**: Never the same quest twice (procedurally generated)
- **Contextual**: Adapted to the player's achievements and current situation
- **Rewarding**: Completion grants powerful items, rare fruits, weapons, or special abilities
- **Progressively Challenging**: Difficulty scales based on player capabilities

### How It Works

When the player encounters an NPC Storyteller, they receive a fresh quest generated in real-time:

**Example Quest Flow:**
1. Player approaches NPC named "Elara the Wise"
2. Elara observes: "You've slain 3 wolves and collected 5 apples. The fire spreads near the tundra."
3. Elara summons the oracle (Gemini API) to generate a quest
4. **Generated Quest**: "Venture to the Fire-Scorched Plains and retrieve 3 Yew Berries before the flames reach the Sacred Grove. Reward: A staff that grants fire and a rare coated axe."
5. Quest appears in player's active quests with objectives and rewards
6. Player completes objectives (navigate to location, gather items, defeat specific creature)
7. Return to NPC and claim reward

## Integration with Engine Components

### **1. Extends `Actor` 
- NPC is a new actor type that participates in the world
- Has behaviors, can be on the map, can interact with player
- Uses the same turn-based system as Player and creatures

### **2. Implements `Behaviour` 
- `QuestGivingBehaviour`: NPC quest-offering behavior using priority system
- Integrates with existing behavior tree priority system
- NPCs can patrol, detect player, and offer quests based on game state

### **3. Uses `Action`
- `AcceptQuestAction`: Player accepts a quest from NPC
- `CompleteQuestAction`: Player submits quest completion to NPC
- `ViewQuestAction`: Player views active quest details

### **4. Uses `Item`  `
- Quest rewards can be items that go into player inventory
- Certain quests require collecting specific items

### **5. Uses `Weapon`
- Quest rewards can include unique enchanted weapons (generated by API)
- Weapons can have API-generated descriptions and special effects

## Key Features

### **1. Contextual Quest Generation**
The system analyzes the game state and sends a prompt to Gemini API:

```
Example API Prompt:
"Generate a quest for an NPC healer named 'Sage Theron' based on:
- Player defeated 4 wolves and 1 bear
- Player has collected 12 apples, 3 hazel nuts, 2 yew berries
- Current health: 80/100, warmth: 45/100, hydration: 60/100
- Fire terrain has spread to 3 locations in the forest
- No creatures tamed yet

Generate a quest with:
- Title and description (2-3 sentences)
- 2-3 specific objectives (COLLECT, DEFEAT, EXPLORE)
- 2-3 rewards (items, weapons, abilities)
- Difficulty rating 1-10
"
```

### **2. Dynamic Difficulty Scaling**
- Easier quests if player is weak
- Harder quests if player has many achievements
- Reward quality scales with difficulty

### **3. Quest Persistence**
- Quests saved with the game state
- Can track progress across multiple turns
- Rewards don't repeat (API generates new ones each time)

### **4. Multiple NPC Locations**
- Storyteller in Forest 
- Sage at Plains 
- Hermit in Cave
- Wanderer at Teleport locations

Each has unique personality and quest themes (API can adapt for each NPC type).

### **5. Time-Limited Quests** 
- Some quests have turn limits
- Adds urgency and challenge
- Creates interesting risk/reward decisions
